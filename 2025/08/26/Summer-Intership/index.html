Summer-Intership

Ray Scout Lv3
  2025-08-26 15:42:16 2025-08-26 15:42:16 创建   2025-09-13 22:23:36 2025-09-13 22:23:36 更新  
  • Diary 
 

Introduction

开始的时候，反复删改这些文字，犹豫怀疑是否是自己情感太过丰富，但后来索性抛弃这些想法，与其花时间和自己内耗，不如想到什么就写一些什么，权当是反思自己这段时间的学习与复盘了。就算留下的是一些没有意义的文字，就当做是埋在 21 岁的时间胶囊，等待 21 年后的PXY 再来发掘，也许那时候会别有一番滋味吧。

以下内容是我在 2025 年 8 月中旬与我的团队”Squirrel Agents”在公司实习做基础的软件开发项目过程中，直接或间接了解学习和发掘的感想，虽然都只是一些基础或者普通的道理，但是当我身体力行的时候才会发觉，要做到自己所认同的事情，往往并没有那么简单。

Abstract

  • 团队协作

    • 一位全副武装的勇士固然能解决很多困难，但是面对一群轻装上阵的武士，就显得臃肿愚蠢了。

  • 个人定位

    • 在一个团队中，要充分发挥每一位队友的主观能力，而不是让他们做你的思路执行者。

  • 了解自己

    • 面对困难时刻的学习能力，面对挫折时刻的抗压能力。

第一周

 

2025/8/18-2025/8/24

 

周一的上午第一次接触不同专业的同学，虽然并不了解他们专业所擅长的方向和学习技能，但是从交谈的过程中发现，这是一群愿意沟通交流的同学；相较于之前组队的同学，似乎不需要太多的去关注男女生之间的距离差异、抑或者是由于性格导致的沟通障碍，这使得我可以将更多的重心放到技术的学习而非人际关系与边际管理（虽然这也是需要关注且十分重要的方面，但是无疑减轻了我的心理负担）

周一的下午，短暂的接触过后大家就开始着手于项目的选择和沟通，大家开始对软件的构建自己的预期，但是我并没有参与其中，并不是说我对软件的构想不感兴趣，而是我更希望从技术的角度出发，选取一个好的项目，后续可以基于这个项目锻炼和丰富自己的技能仓库。鉴于GitHub 更加广泛的使用场景，我选择通过镜像 GitHub 至 gitee 而非直接在 gitee 上部署项目（这是出于长远的角度考虑，虽然这需要多花一些时间去配置额外的功能，但总体来看是值得的）

周一的下午并没有完成上述所说的 GitHub 镜像 Gitee，目前来看还是下午的时间不够耐心，没有认真思考；当时当晚上，自己一个人在教室静下心来之后，将一系列复杂的问题拆解成一个个小问题时，问题的解决就只是时间问题而已。

周二一天基于选择的开源项目，我们尝试去运行和理解整体项目的架构，以方便我们后续针对项目去进行学习、开发、完善。但是也就是从这一天开始，我发现了自己在“团队协作”与“个人定位”上存在的一些重大问题。从这一天的 clone 仓库、配置环境、运行程序开始，我并没有按照自己预先所设想的分享经验、大家自主学习的方案，而是我全权操作、独揽大权，也正是这个错误的想法，导致了后续自己内耗的情绪问题。由于周二还只是比较简单的基础操作，我只需要在每个人的电脑上重复相同的操作即可，最多也只是体力上的劳累。

但是很快，周三的时候就显现出了弊端，由于我们前期采取了错误的策略，没有选择分支并行开发（因为当时觉得学习新的开发技能太过繁琐，所以选择了最简单的方法），选择了每个人各自开发，最终人工合并的方法。一整天我们都在错误的道路上越走越远，直到下午结束我才发现可能是我们开始选取的方向错了，也是这时候我开始发现，我可能需要多听一听其他同学的意见，让每位同学都充分发挥他们各自的主观能动性，而不是做我想法的执行者。

由于本人偷懒，周四、周五这几天忘记记录，等到第二周再回来写博客时发现记忆已经丢失，印象中这两天也是有蛮多收获和感悟的，大抵也是关于个人和团队方面的学习收获，只可惜无从考究。权当做一次教训，下次不要再犯，及时记录，勿要偷懒。

周六、日调整自己的内耗情绪，调整状态。在面对客观的事情、主观的内心，都未能很好的控制自己的情绪，情感会被外界的变化而扰动；同时自己眼光太过狭隘，只局限于眼前的计较，却未从长远的角度考量，“牢骚太盛防肠断，风物长宜放眼量”，好在短时间内及时调整好了状态，也算是有些许进步。

   

第二周

 

2025/8/25-2025/8/31

 

周一，一晚上速通 api 接口。虽然只是简单的调用接口，但是我发现能够利用自己的特长和技能，为团队成员解决他们所遇到的困难，这是一件令人欣喜的事情。从中收获的不仅是来自于队友们的夸奖，更重要的是自己曾经的学习，在此刻得到了收获，好似reinforcement learning 中的 reward function. 也让我更加坚定良好的学习习惯一定会在未来的某个时刻得到嘉奖与回报。

 

周二，修复合并问题。前期准备工作的不足导致在后期合并操作过程中出现了一系列问题，但是这时候凭借自己较为出色的抗压能力，在晚上及时地帮助团队恢复丢失的数据。也是在这时候，我发现自己曾经的经历成为此刻区别于一般同学的特点：1.面对困难时刻的学习能力 2.面对挫折时刻的抗压能力 ；这两项看似简单的能力，确是我与几年前自己最大的区别，也将是我继续深耕的能力。

 

周三，调整 UI 界面，准备速通 YOLO。

 

周四，晚上回到学校后，吃完晚饭洗漱过后便赶到实验室和队友汇合，到达实验室的时候我才发觉大家不只要兼顾这次的暑期实训，同时还需要准备他们的物理实验竞赛，这个团队里的每一位同学都在努力扎根、默默进步，印象最深的是同学们能够熟练的斡旋于实验和理论两个方面，看似轻松写意的背后实则是难以想象的付出，这种感觉或许只有真正经历过的人才能感同身受。只是一次短暂的加班合作，却成为最宝贵的片段。时间在讨论中流逝，深夜的实验室是如此安静，有那么一刻我似乎有些恍惚，好似回到了起几个月前和 CC 学长在数学机房自习的时光，那是一段美好的时光–我能够和学校里最优秀的一批同学交流学习的方法技能、讨论生活的收获与感悟、探讨未来的发展与希冀，而这些养分至今仍旧滋润和哺育着我，促使我不断克服困难、坚持进步、靠近理想。从 CC 学长那里了解到那些他曾经历的“迷惘”和“痛苦”，成为我往后遇到”困难“时刻的坐标，站在时光的岔路口，回望时空隧道的彼时彼刻，在这个坐标下也曾有人承受着相同的苦痛，深夜里佝偻的背影、寂静中重叠的啜泣，过去与未来在想象中交汇，内心也就不再感到孤独，片刻过后，“我又划着我的断桨出发了”。习惯了独来独往的我也开始羡慕大家拥有交谈的伙伴，而我又该去哪里找人交谈呢，回想起来似乎又有几个月没有阅读，好似几个月没有修剪的野人，内心情感开始肆意生长。

 

周五，两周的时光在键盘的敲击中溜走，和两周前相比，在技术上我学习到了许多，但是我认为在这个过程中真正重要的远是技术之外的收获：我所学习到的团队协作、团队沟通、团队定位，这些是我一个人永远无法学习到的技能。就像 Neal（这里推荐 WhynotTV Podcast）和 胡渊鸣 的播客中谈到的“一个人如果把自己关在办公室里，每天做自己的事情，短时间内当然能够产出很多，但是五年之后你一定不知道自己该做什么”，我想如果大学五年我拒绝所有的社交，我或许能够收获很多成果，但是大学毕业之后，我一定不会知道如何和人正确沟通、如何创建一个好的团队、更无从谈起组建一个好的 team 去做一些能够改变世界的事情。但是短短两周，和大家的合作过程中，我收获的不仅仅是团队合作的方法、大家对我能力的肯定也让我对自己有更加清晰的认识。虽然距离本次实习结束还有一个星期，但我还是想提前感谢大家这段时间的付出，非常感谢 hdy 同学组建这么一支优秀的团队，我从此次的合作中受益匪浅，也期待在未来能够有机会继续和大家合作学习。最后祝愿大家能够从事自己热爱的事业、成为自己理想中的自己。
